# Admin ZAYRA — version V31

Le nouvel espace de gestion facile à utiliser est dans `admin/index.html` (ou `/admin/` une fois le site hébergé).

Lire **LIRE_V31_ADMIN.md** pour le guide complet : commandes fictives, stock, clients fictifs, produits, rapports, sauvegarde, démarrage Windows/Mac.

**Attention :** cette version reste une démonstration 100 % front-end, non protégée par une authentification et sans base de données ni connexion aux commandes de la boutique. Elle ne convient pas à de vrais clients ni à des transactions commerciales réelles. Les données ne sont conservées que localement dans le navigateur.
