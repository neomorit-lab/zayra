# ZAYRA V44 — Carrousel des avis produits

- L’affichage en grille V43 a été remplacé par un carrousel pleine largeur : un avis visible à la fois.
- Flèches précédent/suivant, indicateurs de position, glissement tactile sur mobile et contrôle au clavier.
- L’affichage est synchronisé avec les vrais avis publiés via Admin > Avis clients, sans changement du système de données.
- En absence de vrais avis : illustrations de démonstration clairement identifiées comme fictives, sans moyenne de note ni attribution à des clients réels.
- Français et arabe pris en charge, sans dépendance externe pour le slider.
- Le site reste sans backend : pour publier les avis sur tous les appareils, exporter le fichier `assets/reviews.js` depuis l’admin et le déposer sur l’hébergement.

## Ouvrir le projet
Décompresser entièrement l’archive puis ouvrir `ZAYRA_SITE/index.html` ou utiliser les lanceurs Windows / Mac-Linux inclus.
L’espace d’administration est dans `ZAYRA_SITE/admin/`.
