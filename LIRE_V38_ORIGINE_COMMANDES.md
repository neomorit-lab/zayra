# ZAYRA V38 — Origine des commandes

## Nouvelle commande
Dans `/admin/` → **Commandes** → **Ajouter une commande**, choisissez obligatoirement la **Source de la commande** : Site web, Instagram, WhatsApp, Facebook, TikTok, Téléphone, Vente directe, Recommandation ou Autre. Vous pouvez préciser le nom de la campagne, le compte ou le partenaire dans « Précision ».

## Suivi
La source est affichée dans la liste, la fiche et l’export Excel/CSV. La liste peut être filtrée par source. La rubrique **Rapports** contient une répartition par source pour les commandes non annulées (nombre et chiffre d’affaires livré).

## Compatibilité
Les commandes déjà saisies sont conservées. Les anciennes sources Instagram, WhatsApp et Téléphone sont reprises. Les anciennes commandes marquées « Manuel » sont **Non renseignées**, et peuvent être corrigées dans la fiche. Les sauvegardes V31–V37 peuvent être importées et une nouvelle sauvegarde V38 inclut ces champs.

## Important
Le choix « Site web » est une attribution déclarée lors de la saisie. **Aucune commande ne remonte automatiquement depuis la boutique** sans backend ou connexion à un service de commandes. Les informations restent dans le stockage local du navigateur : pas de stockage sécurisé de données personnelles réelles.
